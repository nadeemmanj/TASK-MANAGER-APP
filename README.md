# Task Manager App

A full-stack Task Manager application built with React.js, Node.js, Express.js, and MongoDB. The application allows users to create, view, update, complete, and delete tasks through a RESTful API.

## 🚀 Features

- Create new tasks
- View all tasks
- Update tasks
- Delete tasks
- Mark tasks as completed
- RESTful API
- MongoDB database integration
- Responsive UI
- Toast notifications
- API error handling
- Frontend and backend separation

## 🛠️ Technologies Used

### Frontend
- React.js
- JavaScript
- Tailwind CSS
- React Toastify

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- REST API

## 🔄 CRUD Operations

This application implements complete CRUD functionality:

- **Create** — Add a new task
- **Read** — Fetch and display tasks
- **Update** — Edit task details and status
- **Delete** — Remove tasks
